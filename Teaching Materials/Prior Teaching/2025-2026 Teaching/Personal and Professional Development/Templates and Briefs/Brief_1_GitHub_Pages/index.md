# Assessment Brief 1: GitHub Pages Portfolio

**Weight:** 30% of final grade
**Submission Deadline:** [To be announced]

---

## Overview

Create a professional GitHub Pages website and reflect on your development process. This assessment demonstrates both your ability to create professional materials (Skills Demonstration) and produces artifacts for your portfolio (Collection of Work).

---

## What to Submit

### 1. Live GitHub Pages Website

A functional website at `yourusername.github.io` that includes:

- Professional homepage introducing yourself

- Downloadable CV (PDF format)

- “What I Am Working On” section with current projects

- Clear navigation

- Professional, clean design

- Working code in your GitHub repository

### 2. Development Process Reflection (400-500 words)

A written reflection addressing:

- **Planning:** How did you decide what to include? What goals did you set?

- **Process:** What challenges did you face? How did you solve them?

- **Feedback:** How did you incorporate feedback from others?

- **Learning:** What did you learn about yourself professionally?

**Use the provided template:** `template_github_pages.md`

## Grading Criteria

### Website Content and Design (8%)

- **7-8 points:** Professional, polished site with clear purpose and audience awareness. Sophisticated design choices with consistent branding.

- **5-6 points:** Well-organized site with clear professional content. Good design choices appropriate for purpose.

- **3-4 points:** Functional site with required elements present. Basic design appropriate for a portfolio.

- **0-2 points:** Incomplete site, unprofessional presentation, or missing required elements.

### Development Reflection (7%)

- **6-7 points:** Deep reflection showing significant learning and self-awareness. Specific examples from your process.

- **4-5 points:** Thoughtful reflection with specific examples. Clear evidence of learning.

- **2-3 points:** Basic reflection addresses key questions. Some evidence of learning from the process.

- **0-1 points:** Generic reflection without specific examples or minimal engagement with questions.

### Technical Implementation (6%)

- **5-6 points:** Clean, well-structured code. Advanced features implemented successfully. Repository shows good development practices.

- **3-4 points:** Solid code that works reliably. Good use of GitHub for version control.

- **1-2 points:** Basic functional code. Some technical issues but site works.

- **0 points:** Significant technical problems or non-functional site.

### Problem-Solving and Adaptation (5%)

- **4-5 points:** Clear evidence of iterative improvement. Strong problem-solving demonstrated through challenges overcome.

- **3 points:** Evidence of responding to challenges and making improvements.

- **1-2 points:** Some evidence of addressing challenges.

- **0 points:** No evidence of problem-solving or adaptation.

### Professional Presentation (4%)

- **4 points:** Exceptionally professional presentation. Site represents you effectively and appropriately.

- **3 points:** Professional presentation appropriate for the context.

- **2 points:** Adequate professional presentation with minor issues.

- **0-1 points:** Unprofessional presentation or significant presentation issues.
