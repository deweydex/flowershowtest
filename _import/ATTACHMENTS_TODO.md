# Attachment recovery: handoff for a local Claude Code session

This site was imported from the Superhuman Docs (formerly Coda) document
"Joshua Aaron's Webpage" (doc id `XwmZI3vjrc`). The import carried the text,
links and tables of all 138 pages. It could not carry **embedded files,
images, iframes or buttons**, because Coda's markdown export drops them and
the cloud session that did the import had no network route to Coda.

This file lists every page, where it now lives in this repo, how many embed
gaps it has, and which files were already recovered from an older export. It
is excluded from the published site (see `contentExclude` in `config.json`).

## Prompt to give the other session

Copy the block below into a Claude Code session running on a machine that is
logged in to docs.superhuman.com in Chrome and has this repo cloned on branch
`claude/joshua-aaron-webpage-flowershow-kdhcdd`.

```text
You are recovering embedded files and images that a markdown import could not
carry. Read `_import/ATTACHMENTS_TODO.md` in this repo first; it lists every
page of the Superhuman Docs document "Joshua Aaron's Webpage", its URL, the
markdown file it became, and how many embed gaps it has.

For every page with one or more gaps (work top to bottom through the table):
1. Open the page URL in the browser (Playwright with the user's Chrome
   profile, or the Browser tool if available). Wait for it to render fully.
2. Find every embedded thing that is not plain text: images, file
   attachments (PDF, ipynb, docx, zip, py, cs, csv, md, png), embedded
   iframes/videos, and buttons. For each one note what it is, its caption or
   filename, and the nearest heading above it.
3. Download each file and image into `assets/` in this repo. Keep the
   original filename. If a name collides with a different file already in
   `assets/`, add the page's short slug as a prefix.
4. Edit the page's markdown file: put the file at the point where the gap
   is (the run of blank lines under the nearest heading you noted). Use
   `![[filename.pdf]]` for PDFs, `![alt](/assets/filename.png)` for images,
   and `[filename](/assets/filename)` for everything else. Replace the
   generic "## Files" section that the import added if you find the real
   positions. For iframes and videos, paste the embed URL as a plain link
   (YouTube links on their own line become players in Flowershow).
   For buttons, write a one-line note of the button label and what it did.
5. Tick the page off in the table below by changing its Status cell to
   `done`, and add a line under "Log" saying what you placed where.

Do not rewrite prose. Do not rename or move page files (URLs depend on
them). Commit after every ten pages with a message like
"Recover attachments for <section>", and push to the same branch.
Pages marked `no gaps` need no visit. Pages marked `not fetched` had not
been exported when this list was written: treat them as unknown and visit.
```

## Conventions in this repo

- Pages live under folders named after the Coda page titles. A page with
  children is `Folder/index.md`; a leaf page is `Folder/Page.md`.
- Files go in `assets/` at the repo root. Flowershow serves them at
  `/assets/<name>` and resolves `![[name.pdf]]` embeds by filename.
- Internal links are already rewritten to site paths like
  `/Current+Teaching/AI+for+Business`. Leave them.
- The home page (`index.md`) already has the Tally contact form embedded in
  place of the two Coda buttons.
