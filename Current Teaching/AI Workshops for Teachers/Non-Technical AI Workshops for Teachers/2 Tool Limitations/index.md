# Building a Hermeneutic of Suspicion: A Critical Evaluation Exercise

Modern chatbots like ChatGPT, Claude, and Gemini are complex hybrids that combine search, generation, and retrieval. Understanding what each component does well and poorly helps us evaluate outputs critically. This table presents prompts that tend to challenge different types of systems. As a group, discuss which tool type would likely struggle with each prompt and why.

**Important:** These are tendencies, not absolutes. Any given prompt might produce a good answer due to the hybrid nature of modern systems. The goal is to understand underlying limitations, not to memorize rules.

**Note:** The prompts in this exercise do not conform to recommended best practices for using these tools. For guidance on effective prompting, see the Educational Prompting Examples handout available where you found this document.

## Key Takeaway

Modern AI chatbots are unpredictable because they’re hybrids. A prompt that should challenge a pure LLM might work because the system runs a search. A prompt that should work via retrieval might fail because the retrieved documents are misleading. The goal isn’t to predict behavior perfectly but to develop critical evaluation habits: *What kind of information would this require? Where might that information come from? What could go wrong?*

**For effective prompting strategies:** These examples highlight limitations rather than best practices.
