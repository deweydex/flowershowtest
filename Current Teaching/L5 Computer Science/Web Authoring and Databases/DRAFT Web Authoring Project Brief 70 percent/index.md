# Overview and Purpose

This project asks you to design, plan, and build a complete multi-page website that demonstrates advanced web development capabilities beyond your Assignment 1 portfolio. You will work through the full development lifecycle from initial planning through implementation to deployment and maintenance documentation.

The project emphasizes professional web development practices including thoughtful planning, modern layout techniques, responsive design, and comprehensive documentation. Your work will demonstrate mastery of HTML5 and CSS3 while creating a functional website that serves a clear purpose for an identified audience.

# Detailed Requirements

## Planning Documentation ([planning.md](http://planning.md))

Your planning documentation must include:

**Target Audience and Purpose:**

- Clear identification of your target audience

- Explicit statement of website objectives

- Explanation of how the site serves the intended audience

**Design Principles:**

- Discussion of how you applied the four design principles:

  - **Contrast** - How you created visual hierarchy and emphasis

  - **Repetition** - How you maintained consistency across pages

  - **Alignment** - How you created visual organization

  - **Proximity** - How you grouped related elements

**Site Structure:**

- Site map showing the relationship between all pages

- Explanation of your navigation structure and why you chose it

- Description of how users will move through your site

**Visual Design:**

- Wireframes or sketches for at least three different pages (can be hand-drawn and photographed, or created with tools like Figma, MockPlus, Balsamiq)

- Color scheme with explanation of choices

- Typography decisions and rationale

- Layout approach and reasoning

**Development Tools:**

- List of tools used for development (text editor, graphics software, etc.)

- Brief explanation of why you chose these tools

- Any code generators or frameworks considered

## Website Documentation ([readme.md](http://readme.md))

Your readme must include:

- Overview of the website and its purpose

- Description of each page and its function

- Special features or techniques implemented

- Technologies used (HTML5, CSS3, specific techniques)

- Instructions for viewing the site locally

- Link to the live deployed site (GitHub Pages or similar)

- Credits and attributions for resources used

- Brief reflection on what you learned

## Maintenance Documentation ([maintenance.md](http://maintenance.md))

Your maintenance documentation must include:

- Overview of the website structure and organization

- Instructions for updating text content on pages

- Instructions for adding new pages to the site

- Instructions for adding or replacing images

- Instructions for modifying navigation

- Instructions for uploading changes to the hosting platform

- Common troubleshooting scenarios and solutions

- Recommended maintenance schedule and tasks

## Website Technical Specifications

Your website must demonstrate the following:

**HTML Requirements (across all pages):**

*Document Structure:*

- Proper HTML5 DOCTYPE

- Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)

- Proper heading hierarchy on each page

- Meta tags for charset, viewport, description

*Content Elements:*

- Paragraphs with substantial, well-structured text

- Multiple list types (ordered and unordered)

- At least two data tables with proper semantic markup

- Multiple images with descriptive alt attributes

- Internal links between pages

- At least one external link

- At least one form with multiple input types

- Appropriate use of HTML entities

**CSS Requirements:**

*Selectors and Organization:*

- External stylesheet(s) properly linked

- Element, class, and ID selectors used appropriately

- Combination selectors demonstrating understanding

- Organized, well-commented code

*Modern Layout Techniques (REQUIRED):*

- **CSS Flexbox** used for at least two distinct layout patterns

- **CSS Grid** used for at least one major layout section

- Demonstration of responsive design principles

- Mobile-first or desktop-first approach consistently applied

*Typography and Color:*

- Font properties creating clear visual hierarchy

- Custom web fonts (Google Fonts or similar) if appropriate

- Coherent color scheme using CSS variables recommended

- Appropriate line-height and letter-spacing for readability

*Visual Design:*

- Consistent spacing using margin and padding

- Border properties with appropriate use of border-radius

- Background properties (colors, gradients, or images)

- Box shadows or other subtle effects for depth

*Interactive Elements:*

- Link pseudo-classes (`:link`, `:visited`, `:hover`, `:active`)

- Smooth transitions for interactive elements

- Form styling for consistent appearance

- Clear visual feedback for all interactive elements

**Responsive Design:**

- Mobile-responsive layout using media queries

- Content readable on screens from 320px to 1920px width

- Images that scale appropriately

- Navigation that works on small screens

**Browser Compatibility:**

- Website functions correctly in recent versions of:

  - Chrome/Edge

  - Firefox

  - Safari

- Document any known browser-specific issues
