## Technical Requirements

### HTML Elements

**Document Structure:**

- DOCTYPE, html, head, body

- Meta tags (charset, viewport)

- Descriptive title

**Semantic Elements:**

- header, nav, main, section, footer, div

**Content Elements:**

- Heading hierarchy (h1, h2, h3)

- Paragraphs

- Unordered list

- At least one image with alt text

- Links to project pages

- One HTML character entity (©, →, etc.)

### CSS Requirements

**Selectors:**

- Element selectors (p, h1, nav)

- Class selectors (.card, .highlight)

- ID selectors (#header, #main-nav)

**Typography:**

- font-family with fallbacks

- font-size, font-weight, line-height, text-align

**Link States:**

- a:link, a:visited, a:hover, a:active

**Visual Design:**

- color, background-color

- Consistent color scheme

- margin, padding

- border, border-radius
