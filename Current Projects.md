Last updated September 2026.

# dewlab

[dewlab](https://github.com/deweydex/dewlab) is the project I care most about at the moment. It turns a markdown file into a web page where a student reads an explanation, edits the Python underneath it, and runs it. The Python runs inside the browser tab, on the student's own machine. Nothing is installed, nothing is submitted, and no server ever sees their code.

It exists to remove the first-week cost of teaching programming. Instead of an hour spent installing an interpreter, an editor and a package or two across four operating systems, a student opens a link and starts writing Python. The tutorials are written to a plain-language style guide for adult learners, many of them returning to education, many reading in a second language, and many expecting to be bad at maths. The repository holds the build, the tutorials and the reasoning behind every decision.

# Evaluating the Evaluators

My MSc thesis at Technological University Dublin, supervised by [Keith Quille](https://www.keithquille.com), is titled *Evaluating the Evaluators: How Are LLM-Based Tutoring Systems Evaluated in STEM Education?* It asks a question that the rush to put language models in front of learners tends to skip: when somebody claims that an AI tutor works, what did they measure, on whom, and against what? The thesis is complete. What it found feeds directly into how I use, and do not use, these tools in my own classes, and into the workshops below.

# AI Workshops for Teachers

A set of workshops for teachers in further education, in two strands. The non-technical strand is about what these tools are, what they are not, and how to set expectations with students. The technical strand, [From ML to AI for Teachers](https://github.com/deweydex/FromMLtoAI), starts from fitting a line and ends with a working neural network, in notebooks that run on a school computer. The materials live under [AI Workshops for Teachers](/Current%20Teaching/AI%20Workshops%20for%20Teachers) on this site.

# Coding with AI

[Coding with AI](https://github.com/deweydex/2plus1Coding) is a learning activity for Level 5 and 6 computer science students: five project options, from tic-tac-toe to a small machine learning model, each with beginner and advanced starter code, and two ways to work, either in the browser with a notebook and a chat assistant or on the desktop with a command-line one. It comes with a prompting guide for students and a facilitation guide for teachers. The site is at [deweydex.github.io/2plus1Coding](https://deweydex.github.io/2plus1Coding).

# Course materials as repositories

Over the past year I have been moving course materials out of documents and into public repositories, so that they can be read, forked and corrected.

- [everlearning](https://github.com/deweydex/everlearning) is the integrated material for Programming and Design Principles and Maths for Information Technology in 2026-2027: learning outcomes mapped against the QQI module descriptors, tutorials, practice problems, skills demonstrations and enrichment, along with a few courses in their own right, on computer graphics algorithms, Markov chains and text generation, and neural network pruning.
- [Mathematics](https://github.com/deweydex/Mathematics) is a growing set of worksheets, from fractions and exponents through lines, vectors and factoring to derivatives, integrals and an introduction to statistics and probability. Each is written in markdown, with PDF versions and, where it helps, a notebook.
- [WADB Tutorials](https://github.com/deweydex/WADB_Tutorials) teaches HTML and CSS from nothing to a published site on GitHub Pages, with a design section on typography, readability and accessibility. A shorter variant was built for the AI and Machine Learning students' web authoring module. The tutorial site is at [deweydex.github.io/WADB_Tutorials](https://deweydex.github.io/WADB_Tutorials/).
- [HTML, CSS and SQL Interactive Tutorial](https://github.com/deweydex/HTML-CSS-SQL-JS) is a browser-based tutorial with a working SQL playground and no installation, with a teacher version that carries the solutions and notes.

# A writing app

[FAQ](https://github.com/deweydex/FAQ) is a small personal writing tool: timed writing sessions from a prompt deck, private drafts, and a public, searchable, dated site for the pieces worth publishing, all backed by git with no server of its own. It is also where some of the writing on this site will come from.
